# Excel – Images and Shapes

## Overview

This folder contains my Excel practice work on **Images and Shapes**.

Images and Shapes can be used to make Excel worksheets more visual, organized, and easier to understand. I practiced using these features to create a simple Pinterest Analytics visual summary.

## Topics Practiced

- Inserting Shapes
- Adding text inside Shapes
- Formatting Shapes
- Creating KPI cards using Shapes
- Creating section headers
- Creating information and insight boxes
- Inserting arrows
- Aligning and arranging Shapes
- Resizing Shapes
- Inserting Images
- Resizing and positioning Images
- Practicing Image formatting

## Practice Work

I created a **Pinterest Analytics Visual Summary** using Pinterest performance data.

The visual summary includes:

- Total Impressions
- Total Engagement
- Total Saves
- Total Pin Clicks
- Pinterest Performance section
- Top Board
- Second Highlight
- Key Insight
- Supporting Image

## Skills Demonstrated

- Microsoft Excel
- Shapes and Objects
- Image Insertion and Formatting
- Data Presentation
- Visual Layout
- Basic Dashboard Design
- Data Analysis

## Learning Outcome

Through this practice, I learned how to use Images and Shapes to present data in a more visual and organized way. I also practiced creating KPI cards and visual sections that can be useful when designing Excel reports and dashboards.
