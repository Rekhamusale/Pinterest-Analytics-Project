# Excel – Sorting and Filtering

## Overview

This folder contains my Excel practice work on **Sorting and Filtering**.

Sorting and Filtering are important Excel features used to organize, analyze, and quickly find relevant information in a dataset.

## Topics Practiced

* Sorting data from smallest to largest
* Sorting data from largest to smallest
* Sorting text alphabetically
* Sorting data by multiple columns
* Applying filters to a dataset
* Filtering text values
* Filtering numerical values
* Using Number Filters
* Using Text Filters
* Using Custom Filters
* Using multiple filter conditions
* Clearing filters
* Removing filters

## Practice Work

I practiced Sorting and Filtering using Pinterest-related data to:

* Organize data based on different columns
* Identify high and low performing pins
* Filter records based on specific conditions
* Find relevant data quickly
* Analyze Pinterest performance data more efficiently

## Skills Demonstrated

* Microsoft Excel
* Data Sorting
* Data Filtering
* Data Analysis
* Spreadsheet Management

## Learning Outcome

Through this practice, I learned how to organize datasets using sorting and filtering techniques and how to extract specific information from larger datasets for analysis.
