# Topic 11: Subtotals in Excel

## Project Overview
This exercise demonstrates how to summarize Pinterest analytics data by category using the Subtotal feature in Microsoft Excel.

## Dataset
The `Pin_Data` sheet contains 10 Pinterest pin records with:
- Pin Name
- Category
- Impressions
- Engagement

## Excel Features Practiced
- Sorting data by Category
- Subtotal using the SUM function
- Grouping records by category
- Grand Total calculation
- Outline levels to show or hide detail rows

## Results

| Category | Total Impressions |
|---|---:|
| Beauty | 86 |
| Fashion | 83 |
| Home | 95 |
| Kitchen | 383 |
| **Grand Total** | **647** |

## Steps Completed
1. Created a Pinterest analytics practice workbook.
2. Sorted the records by Category.
3. Used Data → Subtotal.
4. Calculated total impressions for each category.
5. Practiced outline controls to switch between summary and detailed views.

## Key Learning
The Subtotal feature calculates summaries whenever a value changes in a selected column. Sorting by that column first helps Excel group the records correctly.
