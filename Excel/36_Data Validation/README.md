# Topic 16: Data Validation and Drop-Down Lists

## Objective
Learn how to control user inputs and prevent incorrect data entry in Microsoft Excel.

## Concepts Practiced
1. Creating drop-down lists using Data Validation.
2. Creating lists using cell ranges.
3. Setting Stop Error Alerts.
4. Whole Number Validation.
5. Text Length Validation.
6. Date Validation.
7. Input Messages.
8. Creating Named Ranges.
9. Creating Dependent Drop-Down Lists using INDIRECT().

## Practical Project
Created a Pinterest data-entry practice workbook with category selection, numeric restrictions, text-length restrictions, date restrictions and dependent product lists.
