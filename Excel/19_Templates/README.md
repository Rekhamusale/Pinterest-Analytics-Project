# Topic 19 – Templates

## Overview

This practice focuses on creating a reusable Excel template for Pinterest analytics reporting.

## Template Sections

The template contains:

* Pinterest Analytics Report Template
* Report Information
* Account Name
* Reporting Period
* Report Date
* Key Performance Indicators (KPIs)
* Pinterest performance data table

## KPI Calculations

Automatic formulas were created to calculate:

* Total Impressions
* Total Engagement
* Total Pin Clicks
* Total Outbound Clicks
* Total Saves

The formulas automatically calculate the totals when new Pinterest data is entered.

## Excel Skills Practiced

* Creating reusable templates
* Formatting worksheets
* Merging and centering cells
* Applying borders
* Adjusting column widths
* Creating KPI sections
* Using SUM formulas
* Creating dynamic calculations
* Designing a reusable reporting layout

## Learning Outcome

Learned how to create a reusable Pinterest analytics template that can be used for future datasets without rebuilding the report structure and KPI calculations from scratch.
