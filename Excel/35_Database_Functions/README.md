# Topic 15: Excel Database Functions

## Objective
Practised Excel database functions using Pinterest pin performance data.

## Functions Practised

| Function | Purpose | Formula |
|---|---|---|
| DAVERAGE | Calculates the average of matching records | `=DAVERAGE(Pin_Data!A1:D11,"Impressions",A1:A2)` |
| DCOUNT | Counts numeric values in matching records | `=DCOUNT(Pin_Data!A1:D11,"Impressions",A1:A2)` |
| DMAX | Finds the maximum value in matching records | `=DMAX(Pin_Data!A1:D11,"Impressions",A1:A2)` |
| DMIN | Finds the minimum value in matching records | `=DMIN(Pin_Data!A1:D11,"Impressions",A1:A2)` |
