# Topic 7: Notes and Comments in Excel

## Project Overview
This project demonstrates how to add Notes and Comments to cells in Microsoft Excel using sample Pinterest analytics data.

## Objective
- Add explanatory Notes to cells.
- Add Comments for discussion and collaboration.
- Understand the difference between Notes and Comments.
- Document useful information alongside data.

## Workbook Details
**File Name:** `Pinterest_Notes_Comments_Practice.xlsx`

**Worksheets:**
1. `Pin_Data` – Contains sample Pinterest pin performance data.
2. `Notes_Practice` – Reserved for additional Notes and Comments practice.

## Practice Completed

### 1. Added a Note
**Cell:** C2  
**Value:** 214 impressions  
**Purpose:** Explained what the impressions value represents in the sample dataset.

### 2. Added a Comment
**Cell:** D3  
**Value:** 2 engagements  
**Purpose:** Added a comment about reviewing the pin's performance when comparing fashion content.

## Key Learnings
- Notes provide simple explanations or reminders attached to cells.
- Comments support discussions and replies, depending on the Excel version and sharing settings.
- Notes and Comments help provide context without adding extra columns to a dataset.

## Skills Practiced
Microsoft Excel, Notes, Comments, cell annotations, and data documentation.
