# Topic 10: Advanced Sorting in Excel

## Project Overview
This exercise demonstrates how to sort Pinterest analytics data using single-level and multi-level sorting in Microsoft Excel.

## Dataset
The `Pin_Data` sheet contains 10 Pinterest pin records with the following columns:
- Pin Name
- Category
- Impressions
- Engagement

## Excel Features Practiced
- Sorting by Impressions (Largest to Smallest)
- Sorting by Category (A to Z)
- Multi-level sorting using Category and Impressions

## Steps Completed
1. Created a Pinterest analytics practice workbook.
2. Entered sample Pinterest pin data.
3. Sorted pins by impressions from highest to lowest.
4. Sorted categories alphabetically.
5. Applied multi-level sorting: Category (A to Z), then Impressions (Largest to Smallest).

## Key Learning
Multi-level sorting organizes data using more than one condition. In this exercise, pins are grouped alphabetically by category and ranked by impressions within each category.

## Tools Used
- Microsoft Excel
- Pinterest sample analytics data
