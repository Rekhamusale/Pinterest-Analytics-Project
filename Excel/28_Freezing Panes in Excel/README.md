# Topic 8: Freezing Panes in Excel

## Project Overview
This exercise demonstrates how to use Freeze Panes in Excel to keep column headings visible while scrolling through Pinterest analytics data.

## Dataset
The `Pin_Data` sheet contains:
- Pin Name
- Category
- Impressions
- Engagement

The dataset contains 10 Pinterest pin records.

## Excel Feature Practiced
- View tab
- Freeze Panes
- Freeze Top Row

## Steps Completed
1. Created a Pinterest analytics practice workbook.
2. Entered sample Pinterest pin data.
3. Used **View → Freeze Panes → Freeze Top Row**.
4. Scrolled down to verify that the header row remained visible.

## Key Learning
Freeze Top Row keeps the first row visible while scrolling down a worksheet. This makes large datasets easier to read and analyze.

## Tools Used
- Microsoft Excel
- Pinterest sample analytics data
