# Topic 6: Removing Duplicates in Excel

## Project Overview
This project demonstrates how to clean a Pinterest analytics dataset by removing duplicate records in Microsoft Excel.

## Objective
- Identify repeated records.
- Remove duplicate rows.
- Keep one copy of each unique record.
- Verify the cleaned dataset.

## Workbook Details
**File Name:** `Pinterest_Remove_Duplicates_Practice.xlsx`

**Worksheets:**
1. `Raw_Data` – Contains the original Pinterest pin records, including duplicates.
2. `Cleaned_Data` – Contains the cleaned dataset after duplicate removal.

## Sample Data

| Pin Name | Category | Impressions |
|---|---|---:|
| Kitchen Storage | Kitchen | 76 |
| Handbag Fashion | Fashion | 45 |
| Beauty Self-Care | Beauty | 57 |
| Home Decor Ideas | Home | 41 |

## Results
- Original data rows: 8
- Unique records remaining: 4
- Duplicate records removed: 4

## Key Learnings
- Duplicate records can affect the accuracy of data analysis.
- Excel's Remove Duplicates feature helps clean repeated data.
- When selecting all three columns, Excel removes rows only when the selected values match across those columns.
- The original dataset can be retained separately for comparison.

## Skills Practiced
Microsoft Excel, data cleaning, duplicate detection, data quality checks, and dataset validation.
