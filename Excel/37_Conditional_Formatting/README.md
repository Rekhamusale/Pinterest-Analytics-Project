# Topic 17: Conditional Formatting – Advanced Practice

## Overview
In this project, I practiced Advanced Conditional Formatting in Microsoft Excel using a Pinterest pin performance dataset.

The purpose was to learn how to highlight important data, identify duplicate values, and visualize performance using different formatting rules.

## Dataset
The dataset contains the following columns:
- Pin Name
- Category
- Impressions
- Engagement

## Skills Practiced

1. **Greater Than Rule** – Highlighted impressions greater than 100 and later changed the threshold to 150.
2. **Equal To Rule** – Highlighted pins with zero engagement.
3. **Duplicate Values** – Identified repeated engagement values.
4. **Data Bars** – Visualized impression values using blue gradient data bars.
5. **Color Scales** – Applied a Green-Yellow-Red color scale to engagement values.
6. **Icon Sets** – Used traffic light icons to compare engagement performance.
7. **Manage Rules** – Viewed existing Conditional Formatting rules.
8. **Edit Rules** – Modified an existing formatting condition.
9. **Delete Rules** – Practiced removing a Conditional Formatting rule.

## Practical Exercises
- Highlighted impressions greater than 100.
- Highlighted zero engagement values.
- Identified duplicate engagement values.
- Applied data bars and color scales.
- Used icon sets for visual comparison.
- Edited and managed formatting rules.

## What I Learned
- How to highlight important values automatically.
- How to identify duplicate data.
- How to visualize numerical data using Data Bars and Color Scales.
- How to use Icon Sets to compare performance.
- How to manage, edit, and delete Conditional Formatting rules.

## Tools Used
- Microsoft Excel
- Pinterest Pin Performance Dataset
