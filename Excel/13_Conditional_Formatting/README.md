# Excel – Conditional Formatting

## Overview

This folder contains my Excel practice work on **Conditional Formatting**.

Conditional Formatting helps automatically format cells based on specific conditions. It makes important values, patterns, and trends easier to identify.

## Topics Practiced

* Applying conditional formatting to a dataset
* Highlighting cells based on specific values
* Highlighting values greater than or less than a given value
* Highlighting duplicate values
* Using color scales
* Using data bars
* Using icon sets
* Modifying conditional formatting rules
* Removing conditional formatting

## Practice Work

I practiced Conditional Formatting using Pinterest-related data to:

* Highlight important values
* Identify high and low values
* Compare data visually
* Identify duplicate values
* Improve dataset readability
