# Topic 18 – Printing

## Overview

This practice focuses on preparing an Excel worksheet for printing and creating a clean, professional printable report.

## Dataset

The Pinterest analytics dataset contains:

* Pinterest Link
* Impressions
* Engagement
* Pin clicks
* Outbound clicks
* Saves

## Tasks Completed

### 1. Page Setup

Configured the worksheet with:

* Orientation: Landscape
* Paper Size: A4
* Margins: Narrow
* Width: 1 page
* Height: Automatic

### 2. Print Area

Selected the Pinterest analytics report and set the required data as the Print Area.

### 3. Header

Added the report title:

**Pinterest Analytics Report**

### 4. Footer

Added:

* Name
* Page number

### 5. Print Preview

Checked the report using Print Preview to ensure the data was properly aligned and visible without important columns being cut off.

## Excel Skills Practiced

* Page Layout
* Page Orientation
* Paper Size
* Margins
* Scale to Fit
* Setting Print Area
* Adding Headers and Footers
* Adding Page Numbers
* Using Print Preview

## Learning Outcome

Learned how to prepare Excel data for printing and create a clean, readable report that fits properly on an A4 page.
