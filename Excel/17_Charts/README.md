# Topic 17 – Charts

## Overview

This practice focuses on creating and formatting different types of charts in Microsoft Excel using Pinterest analytics data.

## Dataset

The dataset contains Pinterest performance metrics such as:

* Pinterest Link
* Impressions
* Engagement
* Pin clicks
* Outbound clicks
* Saves

## Tasks Completed

### 1. Column Chart

Created a column chart to compare **Impressions by Pinterest Link**.

### 2. Bar Chart

Created a bar chart to compare **Engagement by Pinterest Link**.

### 3. Pie Chart

Created a pie chart to show the **Engagement Breakdown** using:

* Engagement
* Pin clicks
* Outbound clicks
* Saves

### 4. Line Chart

Created a line chart to visualize **Pinterest Performance** using:

* Impressions
* Engagement

## Excel Skills Practiced

* Creating charts
* Selecting data for charts
* Choosing appropriate chart types
* Adding chart titles
* Formatting charts
* Comparing Pinterest metrics visually
* Presenting data in a clear and readable way

## Learning Outcome

Learned how to convert Pinterest analytics data into visual charts to make data easier to understand, compare, and analyze.
